# Swatch (Vue sample)

A plugin frontend written with Vue (MK-021), bundled with Vite into `dist/index.js` with Vue
inside. It contributes the `mk-sample-swatch` element to the `palette.preview` point of the
[React sample](../sample-react) and follows the colour that it publishes on `palette.selected`:
two frameworks in the same page, talking only through the event bus of the shell.
