---
id: MK-018
title: Create the Keycloak realm of an organization automatically
area: security
priority: P1
status: done
depends: [MK-002, MK-012]
acceptance:
  - Creating an organization with federation creates its realm with the kernel UI client
    (authorization code with PKCE), the organization-admin role and, when given, a first manager
    with a temporary password shown once.
  - The realm and the email domains are set on the organization, so that its people are sent to the
    realm at once.
  - When the realm cannot be created (Keycloak unreachable, or a realm with that name exists) the
    organization is not created, and the answer says why.
---

Creating an organization that signs in through Keycloak also creates its realm, without manual steps
in the Keycloak console: the client of the kernel UI, the organization-admin role and a first
manager of the organization. The kernel uses a service account of the master realm.
