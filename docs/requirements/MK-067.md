---
id: MK-067
title: Sign-in by email that routes to the identity provider of the organization
area: security
priority: P1
status: proposed
acceptance:
  - An email whose domain is registered by an organization leads to the realm of that organization
    with the address already filled in.
  - An unknown domain and a known one get the same visible answer, so the page does not reveal
    whether an organization exists.
  - After authentication a person with several organizations chooses one, the last used first; with
    one organization nothing is asked.
---

People should type only their email address: its domain selects the realm and the identity provider,
and the address is passed on as login hint so that it is not typed twice. The page must not reveal
which organizations exist. It extends MK-012, where the email domain already selects the realm, with
the same answer for unknown domains and the choice among several organizations.
