title: A parent POM that builds, packages and tests an extension
area: sdk
priority: P1
status: done
depends: [MK-023, MK-050]
acceptance:
  - An extension with Java code and one without it build their package with mvn package on the
    parent.
  - mvn verify runs the tests of an extension with a package.json; -Dskip.npm and -DskipTests skip
    them.
  - The fixtures of the kernel and the extensions written by create-mosaikit-extension are built on
    it.
---

io.github.mosaikit:mosaikit-extension-parent holds the build of an extension, so that the POM of an
extension names only the parent, its coordinates and the APIs its Java code compiles against. mvn
package writes the JAR in lib/ with its Jandex index and target/<name>-<version>.zip with only what
the kernel reads; with a package.json, the frontend is built before the package and mvn verify runs
the tests of the extension on the bench of @mosaikit/testing (MK-050). The version of the extension
API follows the version of the parent. It is published with the extension API.
