---
id: MK-113
title: Content security policy and security headers on every response
area: security
priority: P2
status: proposed
acceptance:
  - Every response of the shell carries Content-Security-Policy, Strict-Transport-Security,
    X-Content-Type-Options, Referrer-Policy and Permissions-Policy.
  - A script from a source the policy does not allow is blocked by the browser.
  - An extension that declares a frame source in its manifest can embed it, and one that does not
    cannot.
---

A minimum security baseline expects a declared content security policy, framing rules, strict
transport, no sniffing of content types, referrer and permissions policies and hardened session
cookies. Extensions declare the extra sources they need. It extends the headers of MK-001 with the
content security policy and the sources declared by extensions.
