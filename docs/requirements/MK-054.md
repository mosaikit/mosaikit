---
id: MK-054
title: Extensions register their resources with the kernel
area: kernel
priority: P2
status: done
decisions: [ADR-0037]
acceptance:
  - An extension registers, updates and removes its resources through the extension API, and the
    kernel lists them by organization, type and owner.
  - A resource registered by an extension appears in the generic features of the kernel, such as
    sharing and search, without code of theirs in the extension.
  - Uninstalling an extension leaves none of its registered resources behind.
---

Sharing, favorites, trash, versions, tags, presence and transfer of ownership all need the kernel to
know the resources that extensions own. An extension registers each of its resources with type,
identifier, title, owner, organization and the link that opens it, and keeps the entry up to date.
The kernel builds the generic features on these entries, while the data of the resource stay with
the extension.
