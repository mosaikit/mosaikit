---
id: MK-062
title: Encrypted store of credentials and service keys for extensions
area: security
priority: P1
status: done
acceptance:
  - An organization administrator stores a credential; it is encrypted at rest and the API never
    returns it in clear.
  - An extension backend reads the credential by name on the server, under the rights of the
    organization, and the browser never receives it.
  - Credentials never appear in logs, exported documents or error messages.
---

Extensions call external services, such as model providers and databases, with keys that must not be
written into shared documents or reach the browser. The kernel keeps them encrypted, and a key can
belong to the installation, to an organization or to a person, the most specific one applying. Only
extension backends receive them, at the moment of the call.

## History

- 2026-10-13: the kernel stores credentials encrypted (envelope encryption under a master key of

- 2026-10-13: extension backends read credentials with the `Secrets` bean of kernel-api, by name, in
