---
id: MK-102
title: Command palette and keyboard shortcuts fed by the commands of extensions
area: shell
priority: P2
status: proposed
acceptance:
  - Ctrl+K opens a palette that searches the commands declared by the active extensions.
  - An extension declares commands with a name, an optional shortcut and an action, and they appear
    in the palette in the language of the person; the shortcut runs the command.
  - Commands the person has no permission for are not listed.
---

Expert users want to reach any command of any app quickly from the keyboard, without more controls
on the screen. The palette is also a natural entry point for the assistant.
