id: MK-115
title: Bill of materials and vulnerability scan in the release build
area: distribution
priority: P2
status: proposed
acceptance:
  - Every release publishes a CycloneDX or SPDX bill of materials.
  - The build fails above the declared vulnerability threshold.
  - An extension built with the parent POM produces its own bill of materials and scan.
---

Secure-development guidelines ask for a bill of materials for each release, a vulnerability scan
with a threshold, declared fix windows and a channel to report vulnerabilities. Extensions built
with the parent POM get the same.

## History

- 2026-10-13: written from the needs of a product built on Mosaikit, reviewed from its backlog; 1 of
  its requirements depend on it.
