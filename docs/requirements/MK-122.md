---
id: MK-122
title: Serve an installation under a path prefix
area: kernel
priority: P1
status: proposed
acceptance:
  - With the prefix set in configuration, the API, the shell and the assets of extensions answer
    under that prefix, and the shell works without changes.
  - Redirects returned by the kernel carry the prefix in their Location header.
  - The installation manual documents the prefix as one line of configuration.
---

Installations are often published behind a reverse proxy under a path such as /product rather than
at the root of a host. The prefix is a configuration property read at start, not a build parameter,
so that images and portable packages can be moved without rebuilding.
