---
id: MK-079
title: Publishing chain and review of extensions for the marketplace
area: marketplace
priority: P2
status: proposed
acceptance:
  - A publish command uploads a signed package with its listing and release notes.
  - Automatic checks reject a package with an invalid manifest, with calls outside its declared
    hosts or with scopes inconsistent with its code.
  - A listing shows the scopes before purchase and becomes visible only after a reviewer approves
    it.
---

Authors need a path from a publish command to a marketplace listing with price, trial, release
notes, screenshots and declared scopes. Automatic checks stop broken or inconsistent packages, and a
person reviews each listing before it is shown. It extends MK-022 and MK-023, which sign packages
and explain how to publish them, with the listing and its review.
