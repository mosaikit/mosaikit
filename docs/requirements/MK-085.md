---
id: MK-085
title: Extension backends subscribe to platform events on the server
area: kernel
priority: P1
status: planned
acceptance:
  - An extension backend declares a subscription to an event type, for example a file created in a
    folder, and is called once for each matching event with its payload.
  - Events are delivered only within the organization where they happened.
  - An event raised while the subscriber is unavailable is delivered after it restarts.
---

Extensions need to start work when something happens elsewhere in the platform, such as a file
uploaded to the file service or an object of another extension changed, without polling and without
a browser open. Unlike the real-time channel to the browser, delivery to backends is durable.
