---
id: MK-112
title: APIs within a national technical interoperability profile
area: kernel
priority: P2
status: proposed
acceptance:
  - The OpenAPI descriptions of the kernel pass the checker of the interoperability guidelines.
  - An extension API generated with the devkit passes the same checker.
  - APIs that declare a security pattern for authentication between administrations get it from the
    kernel.
---

Public bodies require API descriptions that follow a national interoperability profile, with
mandatory fields, naming, versioning and security patterns for authentication between
administrations. The APIs of the kernel follow it, and extensions inherit it through the devkit.
