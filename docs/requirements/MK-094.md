id: MK-094
title: Favorites across extensions
area: shell
priority: P1
status: done
depends: [MK-054]
acceptance:
  - A person marks a resource of any extension as favorite and finds it in one list.
  - Opening a favorite opens the resource in its extension.
  - A favorite of a resource the person can no longer access disappears from the list.
---

People return to the same resources, and one list of favorites across apps saves searching for
them. It works on the resources that extensions register with the kernel.
