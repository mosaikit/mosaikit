id: MK-055
title: "Share a resource with people, groups, the organization, a link or the public"
area: security
priority: P1
status: in-progress
depends: [MK-054]
decisions: [ADR-0037]
acceptance:
  - An extension declares the sharing levels of a resource type, and the kernel offers the same
    sharing dialog for every type.
  - A resource shared for viewing with a group is readable by its members and not by other people of
    the organization.
  - A link created for a resource opens it without an account until it expires or is revoked; after
    that it answers not found.
  - An extension asks the kernel which level the current person has on a resource and gets the same
    answer that the sharing dialog shows.
---

Extensions own resources that people share one by one at levels such as view, use, edit and manage,
with a person, a group, the whole organization, anyone with a link or the public. One model of
subjects and levels, one sharing dialog and one check that extension backends call spare each
extension inventing its own. A link carries a level, an expiry and an optional password, can be
revoked, and every use of it is audited. It extends MK-032, where a row is shared with a team, to
every kind of subject and to levels.

## History

- 2026-10-13: written from the needs of a product built on Mosaikit, reviewed from its backlog; 11
  of its requirements depend on it.
- 2026-10-13: in progress — public API proposed for review (PR #42).
- 2026-10-13: API reviewed and ADR-0037 accepted: links and the public get the lowest level (links
  up to the "use" level of a type, never one that edits), administrators of the organization hold
  every level, granting again replaces the level, an update that removes levels with grants is
  refused. The team sharing of data collections (MK-032) moves onto this model in the
  implementation, which also brings the `@mosaikit/sdk` counterpart and the REST API.
