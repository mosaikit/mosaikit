---
id: MK-128
title: Organizations allow external origins in the content security policy of the shell
area: security
priority: P1
status: planned
acceptance:
  - An administrator of the installation lists external origins (scheme, host, port) that the shell and the frontends of extensions may contact from the browser, for images, data and tiles.
  - An origin that is not listed stays blocked by the content security policy, as today.
  - The listed origins are visible in the administration and every change is in the audit log.
---

The content security policy of the shell allows connections only to the installation itself, so a
frontend cannot read an external service even when that service allows cross-origin calls; every such
call has to go through a server-side proxy. Administrators list the external origins that may be
contacted directly, and everything else stays blocked.

## History

- 2026-10-13: written after a product built on Mosaikit could not let maps read external services directly, even those that allow it.
- 2026-10-13: planned in phase F03 of the plan, with the maintainer's approval.
