---
id: MK-093
title: "Signed, expiring links to stored files"
area: kernel
priority: P1
status: proposed
acceptance:
  - An extension asks the file service for a signed link to a file or to a prefix, valid for a given
    time; a link to a prefix covers every file under it.
  - A request with a valid signature is served without a session, with range requests and cache
    validators.
  - An expired or altered link is refused, and the file stays unreachable without one.
---

Viewers, external tools, embedded pages and download links in notifications fetch files without the
session of the person. Access must stay limited in time, and to what the person who asked for the
link could read, without making the files public. It extends the file service of MK-041 with links
that carry their own grant.
