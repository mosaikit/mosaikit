---
id: MK-106
title: Guard against leaving a page with unsaved changes
area: shell
priority: P2
status: proposed
acceptance:
  - With unsaved changes declared, switching app or organization asks for confirmation, and
    cancelling keeps the page and its changes.
  - Closing the tab with unsaved changes triggers the leave confirmation of the browser.
  - After the extension clears the flag, navigation happens without confirmation.
---

Editors in many extensions lose work when the person switches app or organization, or closes the
tab. The shell lets an extension declare that it has unsaved changes and asks for confirmation
before any navigation that would discard them.
