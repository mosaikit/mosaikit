---
id: MK-073
title: Single-organization mode of an installation
area: kernel
priority: P1
status: planned
acceptance:
  - With the mode on, the list of organizations, the global list of people and the organization
    selector are hidden, and every request uses the implicit organization.
  - The platform administrator and the organization administrator can be the same person.
  - Turning the mode off on an existing installation shows its organization in the list with all its
    data, without migration.
---

Many installations serve one organization, and there the list and the selector of organizations are
noise. A setting hides them, while the same build can later grow to several organizations without
migrating data. It extends MK-016, the portable distribution for one organization, to every
installation.
