---
id: MK-084
title: Mount an extension on a running installation with hot reload
area: sdk
priority: P1
status: proposed
acceptance:
  - A command mounts the extension under development on a local installation, and the shell shows
    it.
  - A change to a frontend file of the extension shows on reload without reinstalling.
  - The developer chooses the installation to use, with a sample organization and data.
---

Extension developers should see a change on a real installation, with a chosen organization and
content, without packaging and installing at every edit. It extends the bench of MK-050, which
starts an installation for one extension, by mounting the extension on an installation that is
already running.
