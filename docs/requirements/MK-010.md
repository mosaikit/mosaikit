---
id: MK-010
title: Errors as RFC 9457 problem details
area: kernel
priority: P1
status: done
acceptance:
  - Domain errors map to 403, 404 and 409 with application/problem+json.
  - Validation errors return 400 with the list of invalid fields.
  - A request body over the HTTP limit is refused with 413 as a problem detail that names the limit.
---

Every error of the API has the same shape and tells the caller what to do.

## History

- 2026-10-14: a request body over `quarkus.http.limits.max-body-size` is refused with 413 as a
  problem detail that names the limit, instead of an empty answer (#115).
