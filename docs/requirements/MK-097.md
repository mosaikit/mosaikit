---
id: MK-097
title: Free tags on resources of extensions
area: kernel
priority: P1
status: done
depends: [MK-054]
acceptance:
  - An extension attaches, replaces and reads the tags of one of its resources through the kernel
    API, and tags are stored in lowercase without duplicates.
  - Typing a tag suggests the tags already used in the organization.
  - A list of resources is filtered by one or more tags, showing the resources that carry any of
    them.
---

People label the resources of any extension with their own words and filter lists by those labels,
with the same gesture and the same suggestions everywhere. If each extension kept its own tags, they
would diverge.
