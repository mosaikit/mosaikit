---
id: MK-056
title: "Permissions declared by extensions, granted through profiles, groups and people"
area: security
priority: P1
status: in-progress
decisions: [ADR-0038]
acceptance:
  - A permission declared in the manifest of an extension appears in the profile editor of the
    organization and is off until granted.
  - A member whose profile lacks a permission gets 403 from the API of the extension, even when the
    UI is bypassed.
  - Granting the permission to a group of the member, or to the member as an exception, makes the
    same request succeed.
  - An invitation that chooses role, profile and groups shows the resulting permissions before it is
    sent.
---

Three fixed roles are not enough to say what each person may do in each extension. Extensions
declare their permissions in the manifest, and new ones arrive switched off; organizations bundle
them into profiles assigned to roles, and add them through groups or as personal exceptions, without
code. The kernel checks them on navigation, routes and API alike, so that an extension backend
cannot be reached around the UI.
