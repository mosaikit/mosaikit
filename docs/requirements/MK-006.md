---
id: MK-006
title: Extension registry with requirement resolution
area: extensions
priority: P1
status: done
depends: [MK-005]
acceptance:
  - Each extension is ACTIVE, INCOMPATIBLE or INVALID, with human readable reasons.
  - An extension whose requirement is missing, inactive or in a wrong version is INCOMPATIBLE,
    transitively.
  - A second extension with an id already installed is INVALID.
  - The platform administrator lists extensions; signed-in people get the frontends of active
    extensions.
---

At start the kernel reads the installed extensions and decides which ones can be used.
