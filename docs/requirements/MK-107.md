---
id: MK-107
title: "Accessibility conformance (WCAG 2.1 AA) of the shell and UI kit, checked automatically"
area: shell
priority: P1
status: proposed
acceptance:
  - An automated check of the shell, sign-in and settings pages reports no WCAG 2.1 AA violation.
  - The shell can be used with the keyboard alone and announces changes of state to screen readers.
  - The test bench offers the same check to extensions, and it runs in their builds.
---

Public bodies must buy software measured at WCAG 2.1 AA (EN 301 549). The shell, the sign-in page
and the UI kit must be verified and kept from regressing, and extensions need the same check for
their own pages. It extends the axe checks of MK-026 and MK-047 to every page of the shell and to
the builds of extensions.
