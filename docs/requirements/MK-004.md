---
id: MK-004
title: Semantic versions and version ranges
area: extensions
priority: P1
status: done
acceptance:
  - Versions follow Semantic Versioning 2.0.0, including pre-release precedence.
  - Ranges support comparators, caret, tilde, partial versions, wildcards, intersection and union.
  - A pre-release matches a range only when the range targets a pre-release of the same version.
---

Extensions declare the kernel versions they run on and the versions of the extensions they need.
