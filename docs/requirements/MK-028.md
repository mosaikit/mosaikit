title: Themes as theme extensions
area: extensions
priority: P2
status: done
depends: [MK-026, MK-027]
acceptance:
  - Installing a theme extension adds its theme to the settings, and the whole shell and the
    extensions that use the tokens follow it.
  - A theme that misses a token falls back to the value of the default theme.
---

An extension of kind theme brings a set of values of the theme tokens, light and dark, so that an
installation can offer the theme of its brand without changing the kernel. The theme of public
administrations in the style of Bootstrap Italia is built in (mosaikit.ui.theme=pa, ADR-0032).
