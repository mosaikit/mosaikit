---
id: MK-127
title: Credentials of the installation for extensions
area: security
priority: P1
status: planned
acceptance:
  - A platform administrator stores a credential of the installation; it is encrypted at rest like the credentials of organizations and never returned in clear.
  - An extension backend reads a credential of the installation by name on the server, also outside any organization, and the browser never receives it.
  - When an organization and the installation hold a credential with the same name, the extension reads the one of the organization.
---

Some credentials belong to no organization: the administrator account of a map server shared by
the whole installation, a mail relay, a licence key. MK-062 keeps credentials per organization; this
extends the store to the installation, read by extension backends under the same rules, with the most
specific credential applying.

## History

- 2026-10-13: written after a product built on Mosaikit needed the administrator credentials of a server shared by every organization.
- 2026-10-13: planned in phase F03 of the plan, with the maintainer's approval.
