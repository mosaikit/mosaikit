---
id: MK-086
title: Signed outgoing webhooks that extensions can trigger
area: kernel
priority: P1
status: proposed
acceptance:
  - An organization administrator registers a webhook address and secret, and extensions send events
    to it by name.
  - Each delivery carries a signature of the body made with the secret, which the receiver can
    verify.
  - A failed delivery is retried with back-off, and the attempts are visible to the administrator.
---

Extensions need to call external systems, such as help desks, ticketing and automation tools, when
something happens. The kernel offers one way to do it, so that no extension builds its own HTTP
client, retries and signing.
