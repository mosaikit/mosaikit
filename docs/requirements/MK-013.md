---
id: MK-013
title: Signed extension packages
area: distribution
priority: P2
status: done
depends: [MK-011]
acceptance:
  - The kernel refuses a package whose signature or digest does not match.
  - The same package installs identically in portable, container and Kubernetes distributions.
---

Extensions are distributed as zip packages with manifest, code, migrations and translations, signed
with the Ed25519 key of their publisher (ADR-0014). A registry can store the same file as an OCI
artifact; the signature travels inside it.
