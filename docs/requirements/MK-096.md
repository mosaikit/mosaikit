---
id: MK-096
title: Version history of resources
area: kernel
priority: P1
status: done
depends: [MK-054]
acceptance:
  - Each save of a versioned resource creates a version with its author and time.
  - A person with edit rights opens an earlier version and restores it as the current one.
  - The number of kept versions follows a configured limit.
---

People edit shared resources and need to see earlier versions and go back to one. It extends to the
resources of every extension the versions that MK-042 gives to files.

## History

- 2026-10-13: written from the needs of a product built on Mosaikit, reviewed from its backlog; 1 of
  its requirements depend on it.
- 2026-10-15: in progress.
- 2026-10-15: done: the `Versions` bean of the kernel saves a version at each save, as a snapshot or a
  stored file, with its author and time; whoever reads a resource lists and opens its versions, whoever
  has edit rights (inherited levels included) restores one as the newest, in the audit log;
  `mosaikit.versions.max-per-resource` bounds the versions kept (migration V46).
