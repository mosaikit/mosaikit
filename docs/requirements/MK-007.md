---
id: MK-007
title: Serve extension web assets safely
area: security
priority: P1
status: done
depends: [MK-006]
acceptance:
  - Only active extensions serve assets.
  - Paths that leave the extension directory, the manifest and non-web file types are refused.
  - Assets are served with their media type and X-Content-Type-Options nosniff.
---

The browser loads extension modules from the kernel. Serving files must not expose anything else.
