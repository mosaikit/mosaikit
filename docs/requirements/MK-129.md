id: MK-129
title: Installations pass settings to the kernel and to extensions in every distribution
area: distribution
priority: P2
status: planned
acceptance:
  - The Helm chart and the Docker Compose distribution accept extra settings for the kernel and for the extensions (environment or configuration entries) without changing the chart or the images.
  - Secret settings are read from the secrets of the platform (Kubernetes secrets, files), never written in clear in the values.
  - The documentation of each distribution shows how to set a setting of an extension.
---

Extensions have settings of their own, such as the address of a companion service. The installation
and portable distributions read them from a configuration file, but the Helm chart passes only the
settings it knows. Every distribution accepts extra settings for the kernel and for extensions.

## History

- 2026-10-13: written after a product built on Mosaikit could not set the address of a companion service on Kubernetes.
- 2026-10-13: planned in phase F03 of the plan, with the maintainer's approval.
