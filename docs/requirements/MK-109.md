---
id: MK-109
title: The assistant knows the open app and object and offers its tools first
area: ai
priority: P1
status: proposed
acceptance:
  - The frontend of an extension publishes the current context (app, object type, object id), and
    the assistant receives it with each request.
  - Tools declared for a context are offered to the model only while that context is open.
  - The transcript of each turn shows the context and every tool call made.
---

An assistant docked next to an app must answer about what the person has open. Extensions tell the
assistant which object is open and which of their tools apply to it, so that one panel and one
contract serve every app. It extends the assistant of MK-024, which offers every tool of the active
extensions, with the context of the open app.
