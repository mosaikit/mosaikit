---
id: MK-080
title: "Declared capabilities and scopes of extensions, with consent and re-consent"
area: extensions
priority: P1
status: proposed
acceptance:
  - The install screen lists the declared capabilities in plain words, and installation needs the
    consent of an administrator.
  - A call of the extension to a host it did not declare is blocked.
  - A call made by an extension with scopes runs with the intersection of its scopes and the
    permissions of the person, and the audit records both the extension and the person.
  - An update that adds a scope stays pending until an administrator consents again.
---

An extension declares what it needs: network hosts, storage, credentials and API scopes. An
organization administrator sees it in plain words and consents before installing, and an update that
asks for more waits for a new consent. Scopes only narrow what the person can do, never widen it.
