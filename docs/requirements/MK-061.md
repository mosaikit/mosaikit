---
id: MK-061
title: Tokens on behalf of the signed-in person for external systems
area: security
priority: P2
status: proposed
acceptance:
  - An extension asks the kernel for a token of the current person for a configured audience and
    receives a token whose subject is that person.
  - A request without a signed-in person, or for an audience the organization did not configure, is
    refused.
  - The token expires as the realm settings say and never reaches the browser.
---

Extensions that call external systems, such as databases and other APIs, with one service account
bypass the access policies those systems enforce per person. Through token exchange in Keycloak, the
kernel obtains a token for the signed-in person, limited to an audience the organization declared,
and hands it to the extension backend only.
