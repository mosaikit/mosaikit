id: MK-099
title: Extension state in the address of the page
area: shell
priority: P1
status: planned
acceptance:
  - An extension writes a state string into the address, and opening that address in another
    browser gives the extension the same string.
  - An address opened by a person who is not signed in leads, after sign-in, to the same view of the
    extension with the same state.
  - The back and forward buttons of the browser move between the states written by the extension.
---

People share what they are looking at by copying the address. The shell lets an extension write its
own route and view state into the address and gives it back when the address is opened, also after
sign-in, so that a link reopens the same view without saving anything.
