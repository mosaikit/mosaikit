---
id: MK-105
title: "List page, empty and error states and resizable panes in the UI kit"
area: shell
priority: P1
status: in-progress
decisions: [ADR-0039]
acceptance:
  - The UI kit offers a list page with side facets, a fixed header with the count, grid or row
    layout, and a bar of bulk actions supplied by the extension when items are selected.
  - Below the medium breakpoint the facets open from a button that shows the number of active
    filters.
  - The UI kit offers an empty or error state with title, explanation and action, which tells apart
    nothing yet, filtered out, failed, offline and denied.
  - The person resizes the list pane of an app, and the app keeps that width at the next visit.
---

Apps that list resources need the same shape: facets in a side column, a header with counts, cards
or rows, and a selection bar for bulk actions. Every panel without content must say what happened
and what to do, so that a failed request never looks like an empty list. Names in list panes vary
with language and content, so the person sets their width. It extends the UI kit of MK-026 with
these patterns.
