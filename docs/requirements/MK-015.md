id: MK-015
title: AI tool registry for extension actions
area: ai
priority: P2
status: done
depends: [MK-006]
acceptance:
  - Actions are declared in the manifest with a JSON Schema and a risk level.
  - Write and execute actions require confirmation and are audited.
  - The actions are available through a REST API and an MCP server, and act only on the organization
    of the request with the permissions of the person.
---

Extensions declare typed actions that an assistant and an MCP server can use with the permissions of
the signed-in person, producing drafts that the person confirms. See ADR-0017.
