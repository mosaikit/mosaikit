---
id: MK-120
title: Upgrades without downtime with several kernel replicas
area: distribution
priority: P2
status: proposed
acceptance:
  - With two replicas, a Helm upgrade to a new version keeps the API answering throughout.
  - Migrations run once per upgrade, whatever the number of replicas.
  - During the rollout the old and the new replicas serve requests on the migrated schema without
    errors.
---

A service in high availability must be upgraded without stopping. With several replicas, the schema
migrations of the kernel and of the extensions must stay compatible with both versions during the
rollout.
