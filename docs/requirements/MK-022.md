---
id: MK-022
title: Minimal marketplace with signed catalogs
area: marketplace
priority: P2
status: done
depends: [MK-011, MK-013]
acceptance:
  - The build publishes the packages of the extensions with a signed index, which an installation
    can use as a catalog.
  - A catalog whose index is not signed by a trusted key is refused, and so is a package that does
    not match the index.
  - A platform administrator installs or updates an extension from a catalog, or uploads a package,
    without touching files; the replaced package is kept.
---

An installation reads catalogs of extensions (directories with a signed index, over HTTPS or on a
removable medium for offline transfer), lists what they offer next to what is installed, and lets
platform administrators install or update a package, or upload one, from the interface. Only
packages signed by a trusted publisher and matching the signed index are accepted; they take effect
at the next start. Prototype spike S6. See ADR-0021.
