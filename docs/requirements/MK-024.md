id: MK-024
title: Assistant on the tools of the extensions
area: ai
priority: P2
status: done
depends: [MK-015]
acceptance:
  - A request in Italian is answered with a read tool and a write tool; the write becomes a draft
    and nothing changes before the confirmation.
  - Tool errors are given back to the model, and a conversation is bounded in rounds, messages and
    length.
  - Without a configured model the assistant is off; MCP clients keep using the same tools.
---

The kernel offers an assistant that answers requests in natural language with the tools of the
active extensions (MK-015), through a language model behind an OpenAI-compatible API, local such as
Ollama or hosted. It acts with the permissions of the person in the organization of the request;
changes become drafts that the person confirms. The shell has an assistant panel. Prototype spike
S10. See ADR-0022.
