---
id: MK-046
title: Data of extensions without a backend
area: extensions
priority: P1
status: done
depends: [MK-014, MK-022]
acceptance:
  - The documents of a collection are seen only in the organization that wrote them.
  - A replacement with an old version is refused with 409 instead of overwriting.
  - Only declared collections of active extensions exist; a document is a JSON object.
  - A frontend-only extension installed from the marketplace is usable at once, without a restart.
---

An extension declares collections of documents in its manifest; the kernel keeps their JSON
documents for each organization, under row-level security, and serves them to the frontend of the
extension through the SDK and the bridge. An extension without a backend and without a schema is
active as soon as it is installed, without a restart. See ADR-0031.
