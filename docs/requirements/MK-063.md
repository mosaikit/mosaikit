---
id: MK-063
title: Encryption keys per organization with rotation and external custody
area: security
priority: P2
status: proposed
depends: [MK-062]
acceptance:
  - Each organization has its own data key, wrapped by a master key held in a key service or in the
    store of the operating system.
  - Rotating the master key keeps every existing secret readable.
  - Backups and files at rest are encrypted.
---

Secrets and files must be encrypted with keys of each organization, held outside the configuration
file and rotated without downtime. A master key kept in a key management service, or in the store of
the operating system, wraps the data keys, and backups are encrypted as well.
