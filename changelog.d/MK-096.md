### Added

- Version history of the resources of extensions (MK-096): the `Versions` bean (`kernel-api`,
  `dev.mosaikit.kernel.api.resource`) saves a version of a registered resource at each save, as a
  snapshot kept by the kernel or a file of the file service, with its author and time; it lists and
  opens the versions for whoever holds a level on the resource, and restores one as the newest for
  whoever has edit rights, inherited levels included, writing `resource.version.restored` in the audit
  log. The number of versions kept follows the new setting `mosaikit.versions.max-per-resource` (50);
  a value below 1 removes nothing. Migration V44.
