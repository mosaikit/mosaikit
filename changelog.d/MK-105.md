### Added

- Page patterns in the UI kit (MK-105): `<mk-list-page>` with facets in a side column (from a
  button that shows the active filters below the medium breakpoint), a fixed header with the count,
  grid or row layout and a bar of bulk actions supplied by the app; `<mk-empty-state>`, which tells
  apart nothing yet, filtered out, failed, offline and denied, each with title, explanation and
  action; `<mk-split-pane>`, a list pane the person resizes, with the pointer or the keyboard, and
  that keeps its width at the next visit. Additions to `@mosaikit/ui`; see
  `docs/development/extensions/page-patterns.md`.
