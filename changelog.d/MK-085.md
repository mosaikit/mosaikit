### Added

- Events of the platform for the Java code of extensions (MK-085): an extension subscribes with a
  bean that implements `PlatformEventSubscriber` (`kernel-api`, `dev.mosaikit.kernel.api.events`) and
  raises its own events with `PlatformEvents`. The kernel raises events when an organization is created,
  when an organization turns an extension on or off, when a file is stored or deleted and when a
  resource is registered or removed. Events are written in the transaction of the change (migration
  V30) and delivered at least once, in the organization where they happened, with retries and after a
  restart; the handler runs for the organization without a person (a first part of MK-126), and what
  it does is audited with the extension as actor and the channel `JOB`. New settings
  `mosaikit.events.*`.
